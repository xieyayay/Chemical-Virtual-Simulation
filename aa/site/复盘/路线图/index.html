    复盘路线图¶

    把「看懂这个项目」拆成 22 个可独立完成的小任务。一次只做一行。

    状态：草稿　最后核对：2026-11-19　适用版本：UE 5.7.4

    一、怎么用这份路线¶

    1. 在下面的状态表里挑一行（建议从上往下，不要跳）
    2. 读该行对应的任务卡（本文档第四节）
    3. 复制 docs/_template.md 到目标路径，改文件名，按六段式写
    4. 写完跑 mkdocs serve 看一眼，对照 docs/复盘/写作规范.md 第九节验收
    5. 回来把状态表里的 ⬜ 改成 ✅

    节奏建议：知识卡一次 1 张（20–30 分钟），系统页一次 1 页（2–3 小时）。不要一次开三页。

    三、三条主轴（不是三条路，是三种目的）¶

    同一份事实，写的时候取的角度不同。每页写之前先选一条主轴：

    主轴 面向 写法侧重 典型页面
    补基础 你自己 机制 + 定义 + 官方出处；允许写「为什么这样设计」 kb/*
    接手维护 下一个维护者 资产路径 + 改哪里 + 改完怎么验证 systems/*、assets/*
    改造升级 你自己（进阶） 现状债 + 目标设计 + 迁移步骤 + 回归点 systems/interaction-system.md 第 8 节

    四、任务卡¶

    每张卡的字段：要回答的问题 / 先读什么 / 必须产出的图 / 验收标准。

    L0-1 项目概览（改）¶

    • 要回答：这个工程由几层组成？每层放什么？版本与工具链是什么？
    • 先读：aa.uproject、Config/DefaultEngine.ini、Config/DefaultGame.ini、docs/复盘/架构图.md
    • 必须产出：一张「工程分层图」（编辑器层 / 资产层 / 运行时层 / 站点层）
    • 验收：版本号写成 5.7 并给出来源；目录表覆盖 Content/ 下全部一级目录（含 ThirdPerson、MetaHumans、Spline、quote、shuziren_、Teacher、Anim_character）；删掉「5.4.4」

    L0-2 启动链路与生命周期¶

    • 要回答：从双击 exe 到能操控角色，中间按什么顺序创建了哪些对象？各自活多久？
    • 先读：DefaultEngine.ini 的 GameMapsSettings、BP_ChemistryGameInstance、NewGameMode、BP_playercontroller、L_Login
    • 必须产出：时序图（L_Login → OpenLevel → GameMode 构造 → PC 生成 → Pawn 生成 → HUD/WBP_main），标出「谁在第几帧创建」
    • 验收：能回答「GameInstance 和 GameMode 谁先创建」；标出哪些对象在换关时被销毁

    L0-3 框架五件套职责¶

    • 要回答：GameInstance / GameMode / PlayerController / Pawn / HUD 各自该存什么？本项目实际存了什么？
    • 先读：上述五个蓝图 + E_PlayMode + BP_mode
    • 必须产出：5×3 表（职责 / 本项目实际 / 是否放错层）
    • 验收：给出至少一条「放错层」的判断及依据（例：模式状态若存在 GameMode 会随换关丢失）

    L0-4 模式与结局状态机¶

    • 要回答：有几种模式？怎么切换？什么条件算胜利/失败？
    • 先读：E_PlayMode、BP_mode、WBP_gameover、WBP_victory、WBP_score
    • 必须产出：状态机图（状态 / 迁移条件 / 迁移动作）
    • 验收：能说出「从自由模式切考核模式，哪些对象被重建、哪些数据保留」
